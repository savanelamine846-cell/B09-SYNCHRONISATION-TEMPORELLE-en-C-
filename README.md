B09 : Synchronisation temporelle nanoseconde

Projet de synchronisation de 128 machines industrielles
avec le protocole PTP (IEEE 1588v2) en C++.

Objectif:
Un écart d'horloge (jitter) inférieur à 100 ns.

Outils:
C++, PTP, TSN, POSIX timers, horodatage matériel

Auteurs:
Lamine Savane et Amadou Bah
